3. ОБОЛОЧКА СОВЕТНИКА (ЕДИНСТВЕННЫЕ ДОПУСТИМЫЕ ОТЛИЧИЯ ОТ ИНДИКАТОРА)
--------------------------------------------------------------------------------

3.2. Свойства:

     #property version "1.00"   (номер версии советника H1EA; десятичная часть обязательна)
     #property description как в индикаторе по смыслу, с именем H1EA.

3.3. События:
     OnInit     — та же инициализация состояния, UpdateRanges(), UpdateCountdown(), EventSetTimer(1).
     OnDeinit   — EventKillTimer(); удалить все объекты с PREFIX; ChartRedraw(0).
     OnTick     — CheckForNewRangeCandle(); CheckForNewChartCandle(); UpdateCountdown();

3.4. Почему OnTick+OnTimer оба: как в индикаторе OnCalculate+OnTimer. Таймер нужен, чтобы линии/сигналы/countdown жили, даже если по символу нет тиков. OnTick нужен, чтобы не ждать секунду таймера на живом рынке.
3.5. График объектов: chart_id = 0, как сейчас. Не плодить объекты на других графиках.
3.6. Символ и период графика: _Symbol и _Period текущего графика, как в индикаторе.
3.7. История CandleTimeframe: те же вызовы iTime/iHigh/iLow/iClose/Bars(_Symbol, CandleTimeframe). Если баров мало — те же ранние return.
3.8. Print при старте: аналог строки v5.16, но имя «H1EA v1.0», остальной текст смысла не менять.
3.9. Файлы кода (после закрытия вопросов, не сейчас):

6. РАЗМЕТКА ЛИНИЙ (UpdateRanges) — 1 В 1 С ИНДИКАТОРОМ
--------------------------------------------------------------------------------
6.1. Источник OHLC: ТОЛЬКО CandleTimeframe из настроек. ТФ графика на геометрию линий не влияет.
6.2. Рисуются ТОЛЬКО закрытые свечи: цикл shift = 1 … count. Формирующаяся свеча shift=0 НЕ рисуется.
6.3. count = CandlesBack; если count < 1 → 1; если count > Bars(CandleTimeframe)-1 → Bars-1.
6.4. Если Bars(_Symbol, CandleTimeframe) < 3 → выйти, линии этим вызовом не строить.
6.5. periodSeconds = PeriodSeconds(CandleTimeframe); если <= 0 → 60.
6.6. lengthBars = LineLengthBars; если < 1 → 1.
6.7. lengthSeconds = periodSeconds * lengthBars.
6.8. Для каждого shift:
     candleTime = iTime(_Symbol, CandleTimeframe, shift);
     если candleTime <= 0 → continue;
     highPrice = iHigh(... shift); lowPrice = iLow(... shift);
     если highPrice <= 0 ИЛИ lowPrice <= 0 ИЛИ highPrice < lowPrice → continue;
     lineEnd = candleTime + lengthSeconds;
     создать/обновить:
       HIGH — OBJ_TREND горизонталь highPrice, time1=candleTime, time2=lineEnd, цвет HighLineColor;
       LOW  — OBJ_TREND горизонталь lowPrice,  time1=candleTime, time2=lineEnd, цвет LowLineColor;
       HTXT — OBJ_TEXT у (lineEnd, highPrice), текст GetTimeframeName(CandleTimeframe)+" High", если ShowLabels=true, иначе удалить;
       LTXT — аналогично Low, если ShowLabels=true, иначе удалить;
       RECT — OBJ_RECTANGLE (candleTime, highPrice) — (lineEnd, lowPrice), заливка RangeFillColor, фон, если ShowRangeRectangles=true, иначе удалить.
6.9. Свойства линий 1 в 1: OBJPROP_WIDTH=LineWidth, OBJPROP_STYLE=LineStyle, OBJPROP_RAY_RIGHT=false, OBJPROP_RAY_LEFT=false, OBJPROP_SELECTABLE=false, OBJPROP_HIDDEN=true.
6.10. Подписи: шрифт Arial 8, ANCHOR_LEFT, SELECTABLE=false, HIDDEN=true.
6.11. Прямоугольник: FILL=true, BACK=true, STYLE_SOLID, WIDTH=1, SELECTABLE=false, HIDDEN=true.
6.12. После цикла: RangesBuilt = built (true, если хотя бы одна свеча успешно нарисована).
6.13. DeleteObjectsOutsideHistory(count): объекты с PREFIX, кроме COUNTDOWN, без суффикса времени одной из свечей shift=1..count — удалить.
6.14. ChartRedraw(0).

7. КОГДА ПЕРЕСТРАИВАТЬ ЛИНИИ
--------------------------------------------------------------------------------
7.1. OnInit: UpdateRanges() сразу. LastRangeBarTime = iTime(CandleTimeframe, 0). RangesBuilt = false до успешного UpdateRanges.
7.2. CheckForNewRangeCandle:
     currentRangeBarTime = iTime(_Symbol, CandleTimeframe, 0);
     если <= 0 → return;
     если LastRangeBarTime == 0 → запомнить и return (на старте повторный сигнал закрытия не слать этим путём);
     если currentRangeBarTime != LastRangeBarTime → закрылась свеча CandleTimeframe: запомнить новое время, CheckClosedRangeCandleSignal(), UpdateRanges();
     иначе если !RangesBuilt → UpdateRanges() ещё раз (история могла не загрузиться).
7.3. Новая свеча ТЕКУЩЕГО графика линии НЕ перестраивает. Она только запускает проверку пробитий.

8. ТАЙМЕР COUNTDOWN — 1 В 1
--------------------------------------------------------------------------------
8.1. Если ShowCountdown=false → удалить объект COUNTDOWN и выйти.
8.2. candleOpen = iTime(_Symbol, CandleTimeframe, 0); если <= 0 → return.
8.3. candleEnd = GetCandleEndTime(candleOpen, CandleTimeframe); если candleEnd <= candleOpen → return.
8.4. GetCandleEndTime: для PERIOD_MN1 — первое число следующего месяца 00:00:00; иначе candleOpen + PeriodSeconds(tf); если seconds<=0 → 0.
8.5. База отсчёта сбрасывается, если сменился candleOpen или CountdownBaseRemaining < 0. Тогда CalculateInitialRemaining(candleOpen, candleEnd) и CountdownBaseTick = GetTickCount64().
8.6. CalculateInitialRemaining — каскад часов 1 в 1: TimeTradeServer, затем TimeCurrent, затем tick.time символа, затем TimeLocal; если ничего не попало в [candleOpen, candleEnd): для не-MN1 остаток через modulo PeriodSeconds; иначе candleEnd-now с нижней границей 0.
8.7. remaining = CountdownBaseRemaining - (GetTickCount64()-CountdownBaseTick)/1000; если < 0 → 0; если не MN1 и remaining > periodSeconds → remaining = periodSeconds.
8.8. Текст: при hours>0 "TF до закрытия: HH:MM:SS", иначе "TF до закрытия: MM:SS". TF = GetTimeframeName(CandleTimeframe).
8.9. OBJ_LABEL, угол/смещение/цвет/шрифт/размер из input, SELECTABLE=false, HIDDEN=true.

9. СИГНАЛ ЗАКРЫТИЯ СВЕЧИ CandleTimeframe — 1 В 1
--------------------------------------------------------------------------------
9.1. Вызывается только из CheckForNewRangeCandle при смене iTime(CandleTimeframe, 0).
9.2. Если Bars(CandleTimeframe) < 3 → return.
9.3. closedRangeBarTime = iTime(CandleTimeframe, 1); если <= 0 → return.
9.4. Если closedRangeBarTime == LastRangeCloseSignalBar → return (антидубль).
9.5. Сразу LastRangeCloseSignalBar = closedRangeBarTime.
9.6. rangeClose = iClose(CandleTimeframe, 1); если <= 0 → return (отметка антидубля уже поставлена — как в исходнике).
9.7. Текст сигнала, только если EnableCandleCloseSignal=true:
     "{Symbol}: свеча {TF} закрылась. Close: {price}"
9.8. OnInit: LastRangeCloseSignalBar = iTime(CandleTimeframe, 1) — уже закрытая на момент запуска свеча сигнал НЕ генерирует.

10. ПРОБИТИЯ — 1 В 1
--------------------------------------------------------------------------------
10.1. Триггер: новая свеча ТЕКУЩЕГО графика (смена iTime(_Symbol, _Period, 0)). Не тик внутри свечи.
10.2. Проверяется ЗАКРЫТАЯ свеча графика shift=1 vs High/Low ЗАКРЫТОЙ свечи CandleTimeframe shift=1.
10.3. Guards: Bars(_Period)<3; closedChartBarTime<=0; антидубль LastChartCheckBar; OHLC графика >0; Bars(CandleTimeframe)<2; rangeCandleTime<=0 или range High/Low невалидны или High<Low → return.
10.4. Смена опорной свечи CandleTimeframe (rangeCandleTime != SignalRangeCandleTime): сбросить HighSignalAlreadySent и LowSignalAlreadySent в false. По одной опорной свече — максимум один сигнал High и один сигнал Low.
10.5. Формулы (закрытая свеча графика):
     breakoutUp     = chartClose > rangeHigh
     breakoutDown   = chartClose < rangeLow
     falseBreakUp   = chartHigh > rangeHigh AND chartClose <= rangeHigh
     falseBreakDown = chartLow  < rangeLow  AND chartClose >= rangeLow
10.6. Одна закрытая свеча графика даёт только ОДИН сигнал (return после первого сработавшего).
10.7. Приоритет: реальное пробитие выше ложного. Порядок проверок: breakoutUp, breakoutDown, falseBreakUp, falseBreakDown.
10.8. Пробитие High уходит только если !HighSignalAlreadySent; затем флаг = true. Аналогично Low.
10.9. EnableBreakoutSignals / EnableFalseBreakoutSignals глушат ОТПРАВКУ, но флаг already sent ставится всё равно (как в исходнике: if(условие && !flag) { flag=true; if(enable) SendSignal; return; }).
10.10. Тексты сигналов — дословно как в H4.mq5 v5.16 (ПРОБИТИЕ HIGH/LOW и ЛОЖНОЕ ПРОБИТИЕ HIGH/LOW), подставляя имена ТФ графика и CandleTimeframe.
10.11. OnInit: LastChartBarTime = iTime(_Period, 0); LastChartCheckBar = iTime(_Period, 1); SignalRangeCandleTime = iTime(CandleTimeframe, 1); флаги High/Low = false. На уже закрытой свече графика при старте сигнал не слать.
