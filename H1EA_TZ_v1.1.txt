6. РАЗМЕТКА ЛИНИЙ (UpdateRanges)
--------------------------------------------------------------------------------
6.1. Источник OHLC: только CandleTimeframe. ТФ графика геометрию не задаёт.
6.2. Только закрытые свечи: shift = 1 … count. shift=0 не рисуется.
6.3. count = CandlesBack; если < 1 → 1; если > Bars(CandleTimeframe)-1 → Bars-1.
6.4. Bars(CandleTimeframe) < 3 → return, RangesBuilt этим вызовом в true не ставить.
6.5. periodSeconds = PeriodSeconds(CandleTimeframe); если <= 0 → 60.
6.6. lengthBars = LineLengthBars; если < 1 → 1.
6.7. lengthSeconds = periodSeconds * lengthBars.
6.8. На каждом shift:
     candleTime = iTime(_Symbol, CandleTimeframe, shift); если <= 0 → continue;
     highPrice/lowPrice = iHigh/iLow того же shift;
     если highPrice <= 0 ИЛИ lowPrice <= 0 ИЛИ highPrice < lowPrice → continue;
     lineEnd = candleTime + lengthSeconds;
     HIGH: OBJ_TREND горизонталь highPrice, [candleTime; lineEnd], HighLineColor;
     LOW:  OBJ_TREND горизонталь lowPrice,  [candleTime; lineEnd], LowLineColor;
     HTXT/LTXT: OBJ_TEXT у (lineEnd, price), текст GetTimeframeName(CandleTimeframe)+" High"/" Low"; если ShowLabels=false — удалить;
     RECT: OBJ_RECTANGLE (candleTime, highPrice)-(lineEnd, lowPrice), RangeFillColor, заливка, фон; если ShowRangeRectangles=false — удалить.
6.9. Линии: WIDTH=LineWidth, STYLE=LineStyle, RAY_RIGHT=false, RAY_LEFT=false, SELECTABLE=false, HIDDEN=true.
6.10. Текст: Arial 8, ANCHOR_LEFT, SELECTABLE=false, HIDDEN=true.
6.11. RECT: FILL=true, BACK=true, STYLE_SOLID, WIDTH=1, SELECTABLE=false, HIDDEN=true.
6.12. RangesBuilt = true, если нарисована хотя бы одна свеча.
6.13. Затем DeleteObjectsOutsideHistory(count), ChartRedraw(0).

7. КОГДА ПЕРЕСТРАИВАТЬ
--------------------------------------------------------------------------------
7.1. OnInit: LastRangeBarTime = iTime(CandleTimeframe, 0); RangesBuilt = false; UpdateRanges().
7.2. CheckForNewRangeCandle:
     current = iTime(CandleTimeframe, 0); если <= 0 → return;
     если LastRangeBarTime == 0 → запомнить, return;
     если current != LastRangeBarTime → закрылась свеча CandleTimeframe: обновить LastRangeBarTime, CheckClosedRangeCandleSignal(), UpdateRanges();
     иначе если !RangesBuilt → UpdateRanges() повторно (история не догрузилась).
7.3. Новая свеча графика линии не перестраивает, только пробития.

8. COUNTDOWN
--------------------------------------------------------------------------------
8.1. ShowCountdown=false → удалить COUNTDOWN, return.
8.2. candleOpen = iTime(CandleTimeframe, 0); <= 0 → return.
8.3. candleEnd = GetCandleEndTime(candleOpen, CandleTimeframe); если candleEnd <= candleOpen → return.
8.4. GetCandleEndTime: MN1 — 1-е число следующего месяца 00:00:00; иначе candleOpen + PeriodSeconds(tf); seconds<=0 → 0.
8.5. Живой график (не тестер): как индикатор. Сброс базы если сменился candleOpen или CountdownBaseRemaining < 0. CalculateInitialRemaining каскадом: TimeTradeServer, TimeCurrent, tick.time, TimeLocal; иначе modulo PeriodSeconds для не-MN1; иначе candleEnd-now, минимум 0. Дальше remaining = база − (GetTickCount64()−базаTick)/1000. Ниже 0 → 0. Если не MN1 и remaining > periodSeconds → periodSeconds.
8.6. Текст: hours>0 → "TF до закрытия: HH:MM:SS", иначе "TF до закрытия: MM:SS".
8.7. OBJ_LABEL, угол/смещение/цвет/шрифт/размер из input, SELECTABLE=false, HIDDEN=true.
8.8. GetTimeframeName — те же case, что в H4.mq5 v5.16.
8.9. Живой график: не упрощать countdown до «просто candleEnd − now» — оставить каскад и GetTickCount64, иначе уедем от индикатора на реале.
8.10. Тестер (MQLInfoInteger(MQL_TESTER) == true, включая визуал и оптимизацию):
      remaining каждый вызов считать как (long)candleEnd − (long)TimeCurrent(); если < 0 → 0; если не MN1 и remaining > periodSeconds → periodSeconds.
      GetTickCount64 в тестере не использовать: это часы ПК, на ускорении таймер врёт, а Q5 требует работу по времени теста.
      Линии и сигналы в тестере и так по iTime/TimeCurrent — отдельные ветки им не нужны.

9. СИГНАЛ ЗАКРЫТИЯ СВЕЧИ CandleTimeframe
--------------------------------------------------------------------------------
9.1. Только из CheckForNewRangeCandle при смене iTime(CandleTimeframe, 0).
9.2. Bars < 3 → return. closed = iTime(CandleTimeframe, 1); <= 0 → return.
9.3. closed == LastRangeCloseSignalBar → return. Иначе сразу LastRangeCloseSignalBar = closed.
9.4. close = iClose(CandleTimeframe, 1); <= 0 → return (антидубль уже записан, как в исходнике).
9.5. Если EnableCandleCloseSignal: "{Symbol}: свеча {TF} закрылась. Close: {price}"
9.6. OnInit: LastRangeCloseSignalBar = iTime(CandleTimeframe, 1). Стартовая уже закрытая свеча сигнал не даёт.

10. ПРОБИТИЯ
--------------------------------------------------------------------------------
10.1. Триггер: смена iTime(_Symbol, _Period, 0). Не внутри свечи.
10.2. Закрытая свеча графика shift=1 vs High/Low закрытой свечи CandleTimeframe shift=1.
10.3. Guards как в исходнике: Bars(_Period)<3; время<=0; антидубль LastChartCheckBar; OHLC>0; Bars(CandleTimeframe)<2; range время/High/Low невалидны или High<Low → return.
10.4. Смена rangeCandleTime сбрасывает HighSignalAlreadySent и LowSignalAlreadySent. На одну опорную свечу CandleTimeframe — максимум один High и один Low сигнал.
10.5. Формулы:
     breakoutUp     = chartClose > rangeHigh
     breakoutDown   = chartClose < rangeLow
     falseBreakUp   = chartHigh > rangeHigh AND chartClose <= rangeHigh
     falseBreakDown = chartLow  < rangeLow  AND chartClose >= rangeLow
10.6. Одна закрытая свеча графика — один сигнал, return после первого.
10.7. Порядок: breakoutUp, breakoutDown, falseBreakUp, falseBreakDown. Реальное пробитие важнее ложного.
10.8. Флаг already sent ставится до проверки Enable*. Выключенный Enable глушит отправку, но повтор по той же стороне той же опорной свечи не проходит.
10.9. Тексты — дословно из H4.mq5 v5.16.
10.10. OnInit: LastChartBarTime = iTime(_Period, 0); LastChartCheckBar = iTime(_Period, 1); SignalRangeCandleTime = iTime(CandleTimeframe, 1); флаги false. Стартовая закрытая свеча графика сигнал не даёт.

12.4. Alert в тестере допустим (1 в 1). Если пользователь выключит EnablePopupAlerts — останется Print.
